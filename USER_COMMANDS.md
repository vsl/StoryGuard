# StoryGuard — Commands You Actually Need

## Continue course

```text
$storyguard-course-lesson
```

This is the default command.

No long prompt needed.

## Run an AI experiment outside/inside a lesson

```text
$storyguard-ai-experiment
```

## Review your understanding / interview practice

```text
$storyguard-learning-review
```

## Security review

```text
$storyguard-security-review
```

## Implement an intentional off-course feature

```text
$storyguard-feature
```
