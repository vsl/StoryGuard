# AI Experiment Reports

Write the report only after:

1. developer prediction was discussed;
2. experiment plan was approved;
3. baseline/candidate ran;
4. developer interpreted the result;
5. the conclusion was discussed.

Suggested structure:

```md
# Experiment

## Hypothesis
## Developer prediction
## Baseline
## Candidate
## Dataset/version
## Metrics
## Latency/cost
## Failure analysis
## LangSmith IDs
## Developer conclusion
## Discussion/corrections
## Decision
```
