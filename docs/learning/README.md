# Learning Notes

Learning notes are written only after:

1. interactive discussion;
2. explicit implementation approval;
3. implementation;
4. tests/evals/traces;
5. developer hands-on checkpoint;
6. discussion of the checkpoint.

Do not dump the developer's raw answers here instead of discussing them.

A good note contains actual StoryGuard:
- code paths;
- architecture;
- alternatives;
- failures;
- trace IDs;
- metrics;
- trade-offs;
- English interview questions.
