## Normal command

You only need:

```text
$storyguard-course-lesson
```

No long prompt.

Codex will read `COURSE_PROGRESS.md` and continue automatically.

## Core behavior

Codex must:

```text
ask
→ wait for your answer
→ discuss what is right/wrong
→ show correct mental model
→ propose implementation
→ ask for approval
→ only then write code
```
